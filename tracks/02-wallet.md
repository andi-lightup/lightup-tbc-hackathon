# Crypto Wallet Comparison

Which feature matters when choosing a hardware wallet, and what evidence would let someone check it fairly?

## Starting point

LIGHT UP tests multi-coin and Bitcoin-only devices in separate series. Decide whether the proposed criterion applies within one series or to both. Explain which devices can fairly be compared. [Published methodology and matrices](https://lightupkryptos.de/so-testen-wir/)

## Inputs to prepare

Bring an extract from each series and versioned manufacturer instructions for two or three devices. An actual device is only needed if the claim depends on hands-on testing.

## One possible pilot

Imagine the device has been lost. Using public instructions, check whether the owner can identify what they need for recovery and find the steps that apply to their model and backup type. Write a scoring rule a second reviewer can apply. Distinguish documentation quality from demonstrated recovery success. Use dummy examples only.

**Keeping it current.** Would a new firmware release, model revision or rewritten guide justify another check? Which changes can an editor detect without repeating a device test?

**A question a newsroom could investigate.** For which tested models can owners find complete recovery prerequisites before buying?

## What to submit

Complete the [comparison submission](../templates/comparison.md). Show one before-and-after matrix entry, results for two or three products, the reader-facing view and the outcome of a peer’s attempt to reproduce one row. Include a maintenance plan and a source a journalist could cite. If you choose a different improvement, use the same deliverables.
